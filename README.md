# GRAND MARKET — Single Folder

Upload every file in this folder to the ROOT of your GitHub repository.

Setup:
1. Create MongoDB Atlas database.
2. Create Cloudinary account.
3. Create a .env locally or add these as Render Environment Variables:
MONGODB_URI
ADMIN_PASSWORD
JWT_SECRET
CLOUDINARY_CLOUD_NAME
CLOUDINARY_API_KEY
CLOUDINARY_API_SECRET
4. Deploy as a Node web service on Render.
5. Start command: npm start

Never upload .env or secrets to GitHub.
